1

สร้าง Repository

2

อัปโหลดไฟล์ index.html

3

เปิดใช้งาน Pages

คำแนะนำ: ไฟล์นี้ออกแบบให้เป็น Single-File พร้อมอัปโหลดขึ้น GitHub ได้ทันที
